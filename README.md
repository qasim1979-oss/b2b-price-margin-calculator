# Free Standalone B2B Price & Margin Calculator (.exe)

A fast, lightweight, and 100% offline Windows desktop application designed for manufacturers, wholesalers, and exporters to calculate tiered pricing quotations, profit margins, shipping variables, and bulk volume discounts on the fly.

## 🚀 Key Features
- **Tiered Volume Pricing:** Compute unit pricing, order totals, and gross profits across 3 customizable quantity levels.
- **Dual Calculation Modes:** Support for both standard *Markup on Cost* and *Target Gross Margin* calculations.
- **Volume Markup Adjustments:** Apply sliding scale markup discounts for larger bulk export orders.
- **1-Click CSV Export:** Save itemized financial quotation spreadsheets instantly.
- **100% Offline & Secure:** Keep cost sheets and client pricing models entirely private on your local PC.
